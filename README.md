# Smart Factory IoT Monitoring System

## 📌 Project Overview
This project is an IoT-based Smart Factory Monitoring System developed during my internship. It monitors environmental and operational parameters in real time and enables automation and remote control.

## 🚀 Features
- Real-time monitoring of temperature, humidity, light, and motion
- Automation (auto-ventilation based on humidity)
- Remote monitoring and control via cloud dashboard
- Alarm generation for critical conditions
- Two-node system: Production Line & Warehouse

## 🛠️ Technologies Used
- Arduino Uno
- Embedded C
- MQTT Protocol
- ThingsBoard Cloud
- PicsimLab (Simulation)

## 🔌 Components Used
- DHT22 (Temperature & Humidity Sensor)
- LM35 (Temperature Sensor)
- LDR (Light Sensor)
- PIR Sensor (Motion Detection)
- Relay Module
- LEDs

## 🌐 System Architecture
Sensors → Arduino → MQTT → ThingsBoard Cloud → Dashboard

## 📁 Project Structure
- Node1 (Production Line Code)
- Node2 (Warehouse Code)
- Config Files
- Documentation
